KEYBOARD AI BY ANAS — DAFTAR UPDATE v34.0 (VERIFIKASI REAL-TIME SAAT KEYBOARD TAMPIL + MULTI-DEVICE ID + SCROLL GEMINI TTS RINGAN)

Pembaruan Utama Rilis v34.0:
1. VERIFIKASI PREMIUM REAL-TIME SAAT KEYBOARD / PENGATURAN TAMPIL (TANPA GANGGU MENGETIK):
- Saat keyboard terbuka (`onStartInputView`) atau layar aplikasi/pengaturan aktif, app menempelkan listener real-time Firestore di background secara non-blocking — mengetik huruf/Braille tetap 100% ngebut tanpa delay.
- Jika Admin mencabut Premium, memblokir akun, atau menghapus izin Device ID, tombol Input Suara AI & akses AI langsung terkunci dalam hitungan ~1 detik!
- Begitu keyboard ditutup (`onFinishInputView` / `onWindowHidden`) dan aplikasi keluar latar, listener langsung dilepas (nol pengecekan latar belakang), sementara batas offline grace tetap terjaga 48 jam.

2. KEAMANAN MULTI-DEVICE ID (PULUHAN HP DALAM 1 AKUN GOOGLE VIA PANEL ADMIN):
- HP pertama otomatis mendaftarkan `deviceId` ke `allowedDeviceIds` akun (sesuai aturan keamanan `firestore.rules`).
- Jika akun yang sama login di HP kedua/lain yang Device ID-nya belum terdaftar, akses AI terkunci dan user diberi dialog/pesan jelas lengkap dengan Akun Google, UID, Device ID baru, tombol `Salin Device ID`, serta `Hubungi Admin (WA)`.
- Admin tinggal membuka Panel Admin -> pilih akun user -> `Kelola Multi-Device ID` -> tempel/tambah Device ID (bisa puluhan perangkat dalam 1 akun tanpa ganti akun!).

3. PERBAIKAN SCROLL GEMINI TTS STUDIO + PEMBACA LAYAR:
- Menambahkan `android:windowSoftInputMode="adjustResize|stateHidden"` pada `GeminiTtsActivity`.
- Memindahkan blok judul, badge API key, dan kartu ringkasan status ke dalam `ScrollView` (`fillViewport` + `smoothScrollingEnabled`) dengan padding bawah aman (`56dp`), serta membatasi tinggi `EditText` (`minLines=4`, `maxLines=6` scrollable) sehingga seluruh tombol dari atas sampai bawah tetap terlihat & enteng discroll walau keyboard muncul atau memakai screen reader (TalkBack / Jieshuo).
